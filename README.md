## 🚀 How to Run
1. **Clone the repository**:
   ```bash
   git clone https://github.com/your-username/JAVA-PROGRAMMING.git
   cd JAVA-PROGRAMMING
   ```

2. **Compile a Java file**:
   ```bash
   javac FolderName/ProgramName.java
   ```
   Example:
   ```bash
   javac MemoryGame/MemoryGame.java
   ```

3. **Run the compiled program**:
   ```bash
   java FolderName/ProgramName
   ```
   Example:
   ```bash
   java MemoryGame.MemoryGame
   ```

   **Note**: For programs in packages, use the full class name with package structure.
